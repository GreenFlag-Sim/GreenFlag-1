# Green Flag — Learn Sim Racing

A beginner-friendly sim-racing learning site.

## Files

- `index.html` — the homepage
- `styles.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and image placeholder behavior
- `images/` — add replacement photos here

## Replace the photos

See `images/README.txt` for the expected filenames. Add your photos with those names and the homepage will display them automatically.

## Publish with GitHub Pages

Upload the files and folders in this directory to the top level of your repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, and select the `main` branch and `/ (root)` folder. GitHub will show the published website address there.
