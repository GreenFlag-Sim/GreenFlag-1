IMAGE PLACEHOLDERS

Add your photos to this folder using these filenames. Keep the same filenames, or update the matching src="images/..." in index.html.

- hero-track.jpg — wide hero image; landscape orientation works best
- track-detail.jpg — wide race track photo
- first-laps.jpg — beginner practicing in a sim
- racecraft.jpg — cars racing or approaching a corner
- wheel-setup.jpg — sim racing wheel and pedals
- garage.jpg — home sim racing setup

Until you add each photo, the page shows a labeled placeholder explaining which image belongs there. Use photos you own or have permission to use.
